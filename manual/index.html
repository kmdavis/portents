Portent — manual check

The things a test suite cannot judge. Automated tests already prove the SVG and the ASCII describe the same grid, cell for cell. What they cannot tell you is whether the picture looks like what the text says — whether a door reads as a door.

Every pair below is one tile rendered twice from one parsed grid. If a picture and its text disagree, that is a bug worth reporting, because the test suite believes they match.

1. A random map

Tiles laid on a lattice. Because every tile is 7×7 with centred doors, neighbours line up with no matching logic. A seam where only one side has a door is sealed to wall, so there should be no door anywhere that opens onto solid rock.

Placement is random, not edge-matched, so expect isolated rooms and stretches of blank wall. That is the lattice doing what it was asked, not a bug — picking tiles whose edges agree is a generator's job, and there is no generator yet.

2. Every cell kind

One cell of each kind, drawn and written. Check the glyph is a sensible mnemonic and the shape is recognisable at small sizes.

3. Every tile in the pack

Picture and text side by side, per tile. Doors should sit dead centre on each wall.

4. Dice

Sanity check on formatting: dropped dice struck through, labels carried, totals bold.
