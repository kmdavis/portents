Portents

A solo tabletop RPG engine for AI agents and humans.

An AI game master that cannot fudge the dice. Every roll, card and oracle answer lands in an append-only ledger with a citable id, so a number you were told is a number you can audit.

Play the demo Source

Why a ledger

Ask a language model to run a game and it will happily tell you that you rolled a 17. Nothing rolled. The number was chosen because it suited the story, which is the one thing a game master must not do — and you cannot tell from the outside.

Portents makes the dice real and the record checkable. Rolls the player's character makes are cited inline, so you can look them up: 

The bugbear's axe comes down hard — 19 to hit h-42, and 13 damage h-43.
You are at 9 of 26.

World-generation randomness works the other way. Oracle answers, scene checks, table rolls and card draws are the GM's private scaffolding: they are recorded, but never cited, because knowing which parts of the world the dice decided is knowledge you cannot un-learn.

Try it without installing anything

The demo runs the whole engine in your browser and plays a game with a model of your choosing. You bring an API key; it stays in your browser and goes only to the provider you pointed it at. There is no server in the middle, because there is no server at all — this is a static page.

Campaign state persists in IndexedDB, so a game survives a reload. Dice the player's character rolls come up as a dialog: the human rolls their own, and the result is cited with a ledger id you can look up.

Or install it

npm install -g portents
portents roll 2d20kh1+5 --dc 15
portents map --rooms 9 --seed grimhold
portents oracle yes_no "is the gate still guarded?" --likelihood unlikely
